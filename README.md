# Mandarin dari Nol

Kurikulum belajar Bahasa Mandarin dari nol sampai **HSK 1** — dokumentasi terbuka berbahasa Indonesia, ditulis sambil belajar.

🌐 **Situs:** https://iskandar221201.github.io/mandarin-dari-nol/

## Isi

| Bab | Judul |
|-----|-------|
| 0 | Persiapan: pinyin, nada, keyboard |
| 1 | Salam & Perkenalan |
| 2 | Angka, Waktu & Uang |
| 3 | Radikal & Bedah Hanzi |
| 4 | Kosakata Sehari-hari |
| 5 | Tata Bahasa Dasar |
| 6 | Dialog & Percakapan |

Plus: bank latihan, daftar 150 kosakata HSK 1, dan roadmap ke HSK 2+.

## Pengembangan lokal

```bash
npm install
npm run docs:dev
```
