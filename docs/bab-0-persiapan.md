# Bab 0: Persiapan

Sebelum menghafal satu kata pun, kita kenalan dulu sama "mesin"-nya bahasa Mandarin: aksaranya, cara bunyinya ditulis (pinyin), dan nadanya. Ibarat belajar programming: ini instalasi + setup environment sebelum nulis kode pertama.

Bab ini nggak ada hafalan kosakata. Targetnya cuma satu: kamu paham pinyin, bisa bedain empat nada, dan tahu kenapa 不 kadang dibaca *bú*. Kalau fondasi ini beres, semua bab berikutnya bakal jauh lebih ringan.

## 0.1 — Bahasa Mandarin itu apa sih?

Yang kita pelajari namanya **普通话 (pǔtōnghuà)** — harfiahnya "bahasa umum". Ini bahasa Mandarin standar yang dipakai di Tiongkok daratan, diajarkan di sekolah-sekolah, dan dipakai di ujian HSK.


| Hanzi | Pinyin | Arti |
|---|---|---|
| 普通话 | pǔtōnghuà | bahasa Mandarin standar |
| 汉字 | hànzì | karakter/huruf Mandarin |
| 拼音 | pīnyīn | sistem penulisan bunyi Mandarin dengan huruf Latin |


## 0.2 — Simplified vs Traditional: kenapa kita pakai yang simplified?

Hanzi punya dua versi: **simplified** (goresannya disederhanakan, dipakai di Tiongkok daratan & Singapura) dan **traditional** (bentuk klasik, dipakai di Taiwan, Hong Kong, Macau). Versi simplified dirancang supaya lebih gampang dipelajari.

Buku ini — dan ujian HSK — pakai **simplified**. Contoh bedanya:

| Simplified | Traditional | Pinyin | Arti |
|---|---|---|---|
| 汉语 | 漢語 | Hànyǔ | bahasa Mandarin |
| 钱 | 錢 | qián | uang |
| 爱 | 愛 | ài | cinta |
| 你好 | 你好 | nǐ hǎo | halo (sama di dua versi) |

::: info
Kadang kamu bakal ketemu traditional di dunia nyata — misal caption Threads dari Taiwan. Jangan panik: banyak yang bentuknya mirip, dan polanya bisa ditebak kalau kamu sudah paham komponen hanzi (dibahas di Bab 3).
:::

## 0.3 — Pinyin: nulis bunyi pakai huruf Latin

Satu suku kata Mandarin = **initial** (bunyi pembuka) + **final** (bunyi vokal) + **nada**. Contoh: `hǎo` = `h` + `ao` + nada 3.

**Initial** (bunyi pembuka):

| | | | | |
|---|---|---|---|---|
| b | p | m | f | |
| d | t | n | l | |
| g | k | h | | |
| j | q | x | | |
| zh | ch | sh | r | |
| z | c | s | | |
| y | w | | | |

**Final** (bunyi vokal):

| | | | | | |
|---|---|---|---|---|---|
| a | o | e | i | u | ü |
| ai | ei | ui | ao | ou | iu |
| ie | üe | er | | | |
| an | en | in | un | ün | |
| ang | eng | ing | ong | | |

Yang bacaannya "nggak sesuai dugaan":

- **j** ≈ "c" ringan (kayak "cinta" tapi lebih lembut), **q** ≈ "c" berdesis, **x** ≈ "sy" (kayak "syarat")
- **ü** — monyongkan bibir kayak mau bilang "u", tapi bunyikan "i"
- **zh / ch / sh / r** — lidah ditekuk ke belakang, bunyinya lebih berat dari z / c / s biasa

::: tip
Nggak perlu sempurna di bab ini. Pinyin itu alat bantu baca, bukan target hafalan. Yang penting: tiap lihat pinyin, kamu tahu cara mendekati bunyinya.
:::

## 0.4 — Empat nada + satu nada netral

Nada itu WAJIB di Mandarin — beda nada, beda arti. Ada 4 nada utama + 1 nada netral (ringan).

| Nada | Nama | Cara baca | Contoh |
|---|---|---|---|
| 1 | datar tinggi | datar, tinggi, ditahan | 妈 **mā** |
| 2 | naik | naik kayak lagi nanya "hah?" | 麻 **má** |
| 3 | turun-naik | turun dulu, baru naik | 马 **mǎ** |
| 4 | turun | turun tajam, tegas | 骂 **mà** |
| netral | ringan | pendek, lemas, tanpa tanda | 吗 **ma** |

**Minimal pair** — satu bunyi "ma", empat arti yang beda cuma karena nada:

- 妈 **mā** (nada 1) — ibu
- 麻 **má** (nada 2) — rami
- 马 **mǎ** (nada 3) — kuda
- 骂 **mà** (nada 4) — memaki

::: info
Empat kata di atas cuma contoh bunyi, bukan kosakata HSK 1 — nggak perlu dihafal artinya. Fokus ke beda nadanya dulu.
:::

Nada netral (sering disebut "nada 5") ditulis **tanpa tanda nada**: pendek dan ringan. Contoh: 妈妈 **māma** (ibu), 谢谢 **xièxie** (terima kasih).

**Aturan naruh tanda nada:** kalau ada **a**, taruh di a. Kalau nggak ada a, taruh di **o** atau **e**. Kalau tinggal **i/u**, taruh di huruf yang **terakhir**: l**iù**, h**uì**, j**iǔ**.

## 0.5 — Nada yang berubah: tone sandhi

Dua kata spesial yang nadanya berubah tergantung tetangganya:

**不 (bù, "tidak")** → dibaca **bú** (nada 2) kalau ketemu kata bernada 4:

## 0.6 — Install keyboard Pinyin di HP

Tanpa keyboard Mandarin, kamu nggak bisa latihan ngetik. Install sekali, kepake selamanya:

**Android (Gboard):** Settings → Sistem → Bahasa & input → Keyboard virtual → Gboard → Bahasa → tambah **中文 (简体)** → pilih layout **Pinyin**.

**iPhone:** Settings → General → Keyboard → Keyboards → Add New Keyboard → **Chinese, Simplified (Pinyin)**.

Cara pakai: ketik `nihao`, nanti muncul pilihan 你好 — pilih yang benar. Dari sinilah kebiasaan baca pinyin + lihat hanzi mulai kebangun.

## 0.7 — Tips belajar biar nggak nyerah di minggu pertama

1. **Nada dulu, kosakata kemudian.** Salah nada = salah arti. Biasakan baca pinyin *dengan* tanda nadanya, jangan di-skip.
2. **Jangan tulis nada pakai angka** (ni3 hao3). Selalu pakai tanda nada (nǐ hǎo) — matamu perlu terbiasa lihat bentuknya.
3. **Bedah hanzi, jangan hafal buta.** Tiap karakter punya komponen yang sering membocorkan artinya. Ini dibahas tuntas di Bab 3, tapi mindset-nya mulai dari sekarang.
4. **Ngetik > nulis tangan (buat awal).** Ngetik pakai keyboard Pinyin itu latihan baca yang paling murah. Nulis tangan menyusul buat karakter favoritmu.
5. **Sedikit tiap hari > maraton seminggu sekali.** 15 menit sehari ngalahin 3 jam seminggu sekali.

## Latihan

1. Tulis ulang dengan tanda nada yang benar: `ma1`, `ma2`, `ma3`, `ma4`.
2. Kata 妈 dibaca dengan nada keberapa? Artinya apa?
3. 不 bertemu kata bernada 4 dibaca apa? Kasih satu contoh.
4. 一本书 dibaca apa? Kenapa bukan "yī běn shū"?
5. Mana yang simplified: 国 atau 國?
6. Di suku kata `xué`, kenapa tanda nadanya ada di `e`, bukan di `u`?
7. Apa fungsi pinyin dalam belajar Mandarin?
