# Bab 0 · 0.6–0.8: Praktik Mandiri

## 0.6 — Install keyboard Pinyin di HP

Tanpa keyboard Mandarin, kamu nggak bisa latihan ngetik. Install sekali, kepake selamanya:

**Android (Gboard):** Settings → Sistem → Bahasa & input → Keyboard virtual → Gboard → Bahasa → tambah **中文 (简体)** → pilih layout **Pinyin**.

**iPhone:** Settings → General → Keyboard → Keyboards → Add New Keyboard → **Chinese, Simplified (Pinyin)**.

Cara pakai: ketik `nihao`, nanti muncul pilihan 你好 — pilih yang benar. Dari sinilah kebiasaan baca pinyin + lihat hanzi mulai kebangun.

## 0.7 — Tips belajar biar nggak nyerah di minggu pertama

1. **Nada dulu, kosakata kemudian.** Salah nada = salah arti. Biasakan baca pinyin *dengan* tanda nadanya, jangan di-skip.
2. **Jangan tulis nada pakai angka** (ni3 hao3). Selalu pakai tanda nada (nǐ hǎo) — matamu perlu terbiasa lihat bentuknya.
3. **Bedah hanzi, jangan hafal buta.** Tiap karakter punya komponen yang sering membocorkan artinya. Ini dibahas tuntas di [Bab 3](/bab-3-radikal-bedah-hanzi), tapi mindset-nya mulai dari sekarang.
4. **Ngetik > nulis tangan (buat awal).** Ngetik pakai keyboard Pinyin itu latihan baca yang paling murah. Nulis tangan menyusul buat karakter favoritmu.
5. **Sedikit tiap hari > maraton seminggu sekali.** 15 menit sehari ngalahin 3 jam seminggu sekali.

## 0.8 — Drill nada harian (5 menit)

Nada itu skill otot mulut + telinga. Latihan terbaiknya pendek tapi tiap hari:

1. **Tangga nada** — baca berurutan, 5x: mā → má → mǎ → mà → ma. Rasakan bedanya di tenggorokan.
2. **Minimal pair** — pilih satu pasangan dari tabel di 0.4 (mis. shì/shí), baca bergantian 10x.
3. **Shadowing** — putar audio contoh kalimat di bab-bab berikutnya (ada tombol play-nya), tirukan nadanya sepersis mungkin.
4. **Rekam dirimu** — baca 你好吗？我很好，谢谢。你呢？ lalu dengerin ulang. Bagian yang kedengeran aneh = PR besok.

Lima menit sehari selama seminggu, dan telingamu bakal mulai "ngeh" sendiri kapan nada orang lain salah.
