# Bab 11 · 11.5–11.8: Kegiatan & Kerja

Halaman ini fokus ke aktivitas sehari-hari sampai dunia kerja: dari bersih-bersih rumah dan gosok gigi, sampai rapat kantor dan olahraga akhir pekan. Semua kata di bawah ini kosakata HSK 3.

## 11.5 Kerja & kantor (办公室, 会议, 帮忙, 参加, 决定, 请假, 迟到, 离开, 搬, dll)

| Hanzi | Pinyin | Arti |
|---|---|---|
| 办公室 | bàngōngshì | kantor |
| 会议 | huìyì | rapat |
| 帮忙 | bāngmáng | membantu |
| 参加 | cānjiā | ikut serta |
| 决定 | juédìng | memutuskan |
| 请假 | qǐngjià | izin tidak masuk |
| 迟到 | chídào | terlambat |
| 离开 | líkāi | pergi (meninggalkan) |
| 搬 | bān | pindah (barang) |
| 电子邮件 | diànzǐyóujiàn | email |
| 发 | fā | mengirim |
| 完成 | wánchéng | menyelesaikan |
| 提高 | tígāo | meningkatkan |
| 检查 | jiǎnchá | memeriksa |

| 选择 | xuǎnzé | memilih |
| 要求 | yāoqiú | menuntut |

<div class="contoh"><div class="hz">我明天有一个会议。</div><div class="py">Wǒ míngtiān yǒu yī gè huìyì.</div><div class="id">Besok saya ada rapat.</div></div>

<div class="contoh"><div class="hz">她今天迟到了。</div><div class="py">Tā jīntiān chídào le.</div><div class="id">Hari ini dia terlambat.</div></div>

<div class="contoh"><div class="hz">我决定请假一天。</div><div class="py">Wǒ juédìng qǐngjià yī tiān.</div><div class="id">Saya memutuskan izin satu hari.</div></div>

<div class="bedah"><strong>办公室</strong> (bàngōngshì, kantor) = 办 (bàn, mengurus) + 公 (gōng, umum) + 室 (shì, ruangan). Kantor = ruangan untuk mengurus urusan umum.</div>

<div class="bedah"><strong>迟到</strong> (chídào, terlambat) = 迟 (chí, lambat) + 到 (dào, tiba). Tiba dengan lambat = terlambat. Polanya rapi banget.</div>

<div class="bedah"><strong>决定</strong> (juédìng, memutuskan) = 决 (jué, memutuskan) + 定 (dìng, menetapkan). Dua-duanya soal "mantap", jadi maknanya kuat: benar-benar memutuskan.</div>

<div class="bedah"><strong>搬</strong> (bān, pindah barang) = 扌 (tangan) + 般 (bān, petunjuk bunyi). Pindahan ya pakai tangan, makanya beradikal tangan.</div>

| 笔记本 | bǐjìběn | buku catatan |
| 成绩 | chéngjì | nilai |

<div class="contoh"><div class="hz">我每天练习中文。</div><div class="py">Wǒ měitiān liànxí Zhōngwén.</div><div class="id">Tiap hari saya latihan bahasa Mandarin.</div></div>

<div class="contoh"><div class="hz">老师教我们数学。</div><div class="py">Lǎoshī jiāo wǒmen shùxué.</div><div class="id">Guru mengajari kami matematika.</div></div>

<div class="contoh"><div class="hz">我要努力完成作业。</div><div class="py">Wǒ yào nǔlì wánchéng zuòyè.</div><div class="id">Saya harus berusaha keras menyelesaikan PR.</div></div>

<div class="bedah"><strong>复习</strong> (fùxí, mengulang pelajaran) = 复 (fù, kembali/ulang) + 习 (xí, belajar). Belajar kembali = mengulang. Kebalikan dari 预习 (yùxí, persiapan belajar) kalau nanti ketemu.</div>

<div class="bedah"><strong>中文</strong> (Zhōngwén, bahasa Mandarin) = 中 (zhōng, tengah) + 文 (wén, tulisan/bahasa). Bahasa dari "negeri tengah" (中国).</div>

<div class="bedah"><strong>借</strong> (jiè, meminjam) = 亻 (orang) + 昔 (xī, petunjuk bunyi). Catatan jujur: petunjuk bunyinya agak longgar (xī jadi jiè), tapi polanya jelas: urusan pinjam-meminjam itu urusan antar orang.</div>

## 11.8 Olahraga & hiburan (锻炼, 比赛, 体育, 爬山, 骑, 音乐, 游戏, 节目, 节日, 周末, 故事, dll)

| Hanzi | Pinyin | Arti |
|---|---|---|
| 锻炼 | duànliàn | berolahraga |
| 比赛 | bǐsài | pertandingan |
| 体育 | tǐyù | olahraga (sport) |
| 爬山 | páshān | mendaki gunung |
| 骑 | qí | naik (sepeda/kuda) |
| 音乐 | yīnyuè | musik |
| 游戏 | yóuxì | permainan; game |
| 节目 | jiémù | acara; program |
| 节日 | jiérì | festival; hari raya |
| 周末 | zhōumò | akhir pekan |
| 故事 | gùshi | cerita |

<div class="contoh"><div class="hz">周末我们去爬山。</div><div class="py">Zhōumò wǒmen qù páshān.</div><div class="id">Akhir pekan kami pergi mendaki gunung.</div></div>

<div class="contoh"><div class="hz">我喜欢听音乐，看节目。</div><div class="py">Wǒ xǐhuan tīng yīnyuè, kàn jiémù.</div><div class="id">Saya suka dengerin musik dan nonton acara.</div></div>

<div class="bedah"><strong>锻炼</strong> (duànliàn, berolahraga) = 锻 (duàn, menempa) + 炼 (liàn, melebur). Jujur: arti "olahraga" adalah perluasan makna dari dunia pandai besi (menempa dan melebur logam = melatih), bukan tebakan langsung dari komponennya. Ini kata yang dihafal polanya, bukan ditebak.</div>
