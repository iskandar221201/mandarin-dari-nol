# Bab 11 · 11.13–11.16: Konsep & Kata Fungsi

Sampai Bab 10 kamu sudah pegang kosakata benda, kerja, dan sifat. Halaman ini naik satu level: kata-kata abstrak (penting, pengaruh, kesempatan) dan kata fungsi (konjungsi, keterangan, penegas). Kata-kata kecil inilah yang bikin kalimatmu terdengar dewasa, bukan kayak robot hafalan.

## 11.13 Konsep abstrak (办法, 变化, 方便, 清楚, 影响, 重要, 主要, 简单, 容易, 难, 机会, 水平, 需要, 应该, 必须, 安静, 干净, dll)

Kata sifat abstrak plus tiga modal verb yang wajib dikuasai: 需要 (butuh), 应该 (sebaiknya), 必须 (harus). Bedanya gampang: 需要 itu kebutuhan, 应该 itu saran, 必须 itu kewajiban. Jangan ketukar.

| Hanzi | Pinyin | Arti |
|---|---|---|
| 办法 | bànfǎ | cara; solusi |
| 变化 | biànhuà | perubahan |
| 方便 | fāngbiàn | praktis; gampang |
| 清楚 | qīngchu | jelas |
| 影响 | yǐngxiǎng | pengaruh |
| 重要 | zhòngyào | penting |
| 主要 | zhǔyào | utama |
| 简单 | jiǎndān | sederhana |
| 容易 | róngyī | mudah; gampang |
| 难 | nán | sulit |
| 机会 | jīhuì | kesempatan |
| 水平 | shuǐpíng | level; tingkat |
| 需要 | xūyào | butuh |
| 应该 | yīnggāi | sebaiknya; seharusnya |
| 必须 | bìxū | harus; wajib |
| 安静 | ānjìng | tenang; sepi |
| 干净 | gānjìng | bersih |
| 差 | chà | jelek; buruk |
| 短 | duǎn | pendek |
| 坏 | huài | rusak; jelek |
| 长 | zhǎng | tumbuh; bertumbuh |
| 旧 | jiù | tua; bekas (barang) |
| 老 | lǎo | tua (umur) |

<div class="contoh"><div class="hz">我需要你的帮助。</div><div class="py">Wǒ xūyào nǐ de bāngzhù.</div><div class="id">Saya butuh bantuanmu.</div></div>

<div class="contoh"><div class="hz">学习汉语不难，但是需要时间。</div><div class="py">Xuéxí Hànyǔ bù nán, dànshì xūyào shíjiān.</div><div class="id">Belajar Mandarin tidak sulit, tapi butuh waktu.</div></div>

<div class="contoh"><div class="hz">你明天必须早起床。</div><div class="py">Nǐ míngtiān bìxū zǎo qǐchuáng.</div><div class="id">Besok kamu harus bangun pagi-pagi.</div></div>

<div class="bedah"><strong>机会</strong> (jīhuì, kesempatan) = 机 (mesin, kayak di 手机) + 会 (bisa, HSK 1). "Mesin" yang bikin kamu "bisa" = kesempatan.</div>

<div class="bedah"><strong>水平</strong> (shuǐpíng, level) = 水 (air, HSK 1) + 平 (datar/rata). Permukaan air yang datar = level/tingkat.</div>

> 💡 Pola modal: 需要/应该/必须 langsung + kata kerja, tanpa 的. Contoh: 需要学习, bukan 需要的学习.

Catatan: 长 di sini dibaca zhǎng (tumbuh), bukan cháng (panjang, HSK 2). Satu karakter, dua bacaan, dua arti.

## 11.14 Kata sambung (不但…而且…, 除了, 或者, 还是, 如果, 然后, 只有…才…, 跟, 关于, 根据, 为了, 为, dll)

Kata sambung bikin kalimatmu berlogika: syarat, pilihan, pengecualian, tujuan. Tanpa mereka, kalimatmu cuma tumpukan fakta.

| Hanzi | Pinyin | Arti |
|---|---|---|
| 不但……而且…… | bùdàn…érqiě… | tidak hanya... tetapi juga... |
| 除了 | chúle | selain; kecuali |
| 或者 | huòzhě | atau (pilihan) |
| 还是 | háishì | atau (dalam pertanyaan) |
| 如果 | rúguǒ | jika; kalau |
| 然后 | ránhòu | lalu; kemudian |
| 只有……才…… | zhǐyǒu…cái… | hanya jika... baru... |
| 跟 | gēn | dengan; bersama |
| 关于 | guānyú | tentang; mengenai |
| 根据 | gēnjù | berdasarkan; menurut |
| 为了 | wèile | demi; agar |
| 为 | wèi | untuk |
| 经过 | jīngguò | melewati; melalui |

<div class="contoh"><div class="hz">如果明天下雨，我们就不去。</div><div class="py">Rúguǒ míngtiān xià yǔ, wǒmen jiù bù qù.</div><div class="id">Kalau besok hujan, kita tidak jadi pergi.</div></div>

<div class="contoh"><div class="hz">我跟朋友一起吃饭。</div><div class="py">Wǒ gēn péngyou yīqǐ chī fàn.</div><div class="id">Saya makan bareng teman.</div></div>

<div class="contoh"><div class="hz">他不但会说汉语，而且会写汉字。</div><div class="py">Tā bùdàn huì shuō Hànyǔ, érqiě huì xiě Hànzì.</div><div class="id">Dia tidak hanya bisa ngomong Mandarin, tapi juga bisa nulis hanzi.</div></div>

<div class="bedah"><strong>如果</strong> (rúguǒ, jika/kalau) = 如 + 果 (buah, dari 水果 HSK 2). "Kalau" + "buah" = jika. Ingat buahnya, ingat katanya.</div>

<div class="bedah"><strong>为了</strong> (wèile, demi/agar) = 为 (untuk, bab ini) + 了 (HSK 1). Untuk + penanda selesai = tujuan yang mau dicapai.</div>

> 💡 还是 vs 或者: 还是 dipakai waktu kamu menanyakan pilihan (belum diputuskan), 或者 dipakai di pernyataan (pilihannya bebas). Tanya: 你喝茶还是喝咖啡？ Pernyataan: 喝茶或者喝咖啡都可以.

## 11.15 Keterangan waktu & frekuensi (刚才, 后来, 过去, 最近, 马上, 终于, 一直, 经常, 突然, 总是, 以前, 半, 刻, 分, 万, 久, dll)

Kata keterangan waktu menjawab "kapan" dan "seberapa sering". Posisinya biasanya di awal kalimat atau tepat sebelum kata kerja.

| Hanzi | Pinyin | Arti |
|---|---|---|
| 刚才 | gāngcái | barusan; tadi |
| 后来 | hòulái | kemudian; belakangan |
| 过去 | guòqù | masa lalu; dulu |
| 最近 | zuìjìn | akhir-akhir ini |
| 马上 | mǎshàng | segera; langsung |
| 终于 | zhōngyú | akhirnya |
| 一直 | yīzhí | terus-menerus |
| 经常 | jīngcháng | sering |
| 突然 | tūrán | tiba-tiba |
| 总是 | zǒngshì | selalu |
| 以前 | yǐqián | dulu; sebelumnya |
| 半 | bàn | setengah |
| 刻 | kè | seperempat jam |
| 分 | fēn | menit |
| 万 | wàn | sepuluh ribu |
| 久 | jiǔ | lama (waktu) |
| 最后 | zuìhòu | terakhir; pada akhirnya |
| 一共 | yígòng | total; semuanya |
| 一会儿 | yíhuìr | sebentar |
| 先 | xiān | dulu; lebih dulu |

<div class="contoh"><div class="hz">他刚才出去了。</div><div class="py">Tā gāngcái chūqù le.</div><div class="id">Dia barusan keluar.</div></div>

<div class="contoh"><div class="hz">以前我不会说汉语，现在我会一点。</div><div class="py">Yǐqián wǒ bù huì shuō Hànyǔ, xiànzài wǒ huì yīdiǎn.</div><div class="id">Dulu saya tidak bisa ngomong Mandarin, sekarang saya bisa sedikit.</div></div>

<div class="contoh"><div class="hz">我们一直学习到晚上十点。</div><div class="py">Wǒmen yīzhí xuéxí dào wǎnshang shí diǎn.</div><div class="id">Kami belajar terus sampai jam sepuluh malam.</div></div>

<div class="bedah"><strong>过去</strong> (guòqù, masa lalu) = 过 (lewat, bab ini) + 去 (pergi, HSK 1). Yang sudah "lewat dan pergi" = masa lalu.</div>

<div class="bedah"><strong>最近</strong> (zuìjìn, akhir-akhir ini) = 最 (paling, HSK 2) + 近 (dekat, HSK 2). Waktu yang "paling dekat" dengan sekarang = akhir-akhir ini.</div>

> 💡 三点半 = jam setengah empat (setengah menuju jam 4). 一刻 = 15 menit: 三点一刻 = jam 3 lewat 15 menit.

## 11.16 Kata fungsi & penegas (啊, 把, 被, 过, 地, 更, 比较, 极, 多么, 只/只, 像, 向, 越, 一定, 其实, 当然, 特别, 其他, 一般, 一样, 一边, 一直, 又, 短, 老, 旧, 差, 坏, 种, 双, 段, 坏, dll)

Kata-kata kecil tapi ngaruh besar: partikel, penanda, dan penegas rasa. Tiga di antaranya, 把, 被, dan 过, punya pola grammar sendiri yang diajar tuntas di Bab 12. Di sini kamu cukup kenal arti dasarnya dulu.

| Hanzi | Pinyin | Arti |
|---|---|---|
| 啊 | a | partikel seru ("ah", "lho") |
| 把 | bǎ | memegang (kata fungsi; pola lengkap di Bab 12) |
| 被 | bèi | oleh (pasif; pola lengkap di Bab 12) |
| 过 | guò | melewati (pola pengalaman di Bab 12) |
| 地 | de | penanda keterangan cara ("dengan ...") |
| 更 | gèng | lebih |
| 比较 | bǐjiào | relatif; agak |
| 极 | jí | sangat (amat) |
| 多么 | duōme | betapa |
| 只 | zhī | satuan untuk hewan |
| 只 | zhǐ | hanya |
| 像 | xiàng | seperti; mirip |
| 向 | xiàng | ke arah |
| 越 | yuè | semakin |
| 一定 | yídìng | pasti |
| 其实 | qíshí | sebenarnya |
| 当然 | dāngrán | tentu saja |
| 特别 | tèbié | istimewa; sangat |
| 其他 | qítā | lain; lainnya |
| 一般 | yībān | umum; biasa |
| 一样 | yíyàng | sama |
| 一边 | yībiān | sambil |
| 又 | yòu | lagi; pula |
| 起来 | qǐlái | bangun (pola pelengkap di Bab 12) |
| 双 | shuāng | sepasang |
| 段 | duàn | bagian; ruas |
| 几乎 | jīhū | hampir |

<div class="contoh"><div class="hz">他高兴地说：“我回来了！”</div><div class="py">Tā gāoxìng de shuō: "Wǒ huílái le!"</div><div class="id">Dia berkata dengan gembira: "Aku sudah pulang!"</div></div>

<div class="contoh"><div class="hz">其实我不饿。</div><div class="py">Qíshí wǒ bù è.</div><div class="id">Sebenarnya aku tidak lapar.</div></div>

<div class="contoh"><div class="hz">他跟我一样高。</div><div class="py">Tā gēn wǒ yíyàng gāo.</div><div class="id">Dia setinggi aku.</div></div>

<div class="bedah"><strong>多么</strong> (duōme, betapa) = 多 (banyak, HSK 1) + 么 (dari 什么, HSK 1). "Banyak-bagaimana" = betapa. Dipakai buat seruan kagum: 多么漂亮！</div>

<div class="bedah"><strong>一边</strong> (yībiān, sambil) = 一 (satu, HSK 1) + 边 (sisi, dari 旁边 HSK 1). Satu sisi ngerjain ini, sisi lain ngerjain itu: 一边…一边….</div>

> 💡 地 (de) itu penanda keterangan cara: kata sifat + 地 + kata kerja. Jangan ketukar sama 的 (penanda milik, HSK 1).
