# Bab 11 · 11.1–11.4: Manusia & Masyarakat

HSK 3 nambah 300 kata baru, jadi totalnya 600 kata. Di halaman ini fokusnya manusia dan relasi: keluarga besar, tubuh dan kesehatan, perasaan dan sifat, sampai masyarakat sekitar.

## 11.1 Keluarga & kerabat

HSK 2 sudah ngenalin 爸爸妈妈 sampai 丈夫妻子. HSK 3 nambah generasi kakek-nenek dan om-tante:

| Hanzi | Pinyin | Arti |
|---|---|---|
| 阿姨 | āyí | tante/bibi (juga panggilan akrab untuk perempuan yang lebih tua) |
| 奶奶 | nǎinai | nenek (dari pihak ayah) |
| 爷爷 | yéye | kakek (dari pihak ayah) |
| 叔叔 | shūshu | om/paman |
| 结婚 | jiéhūn | menikah |
| 张 | zhāng | marga Zhang |

<div class="contoh"><div class="hz">我奶奶今年八十岁。</div><div class="py">Wǒ nǎinai jīnnián bāshí suì.</div><div class="id">Nenek saya tahun ini 80 tahun.</div></div>

<div class="contoh"><div class="hz">我叔叔结婚了。</div><div class="py">Wǒ shūshu jiéhūn le.</div><div class="id">Om saya sudah menikah.</div></div>

<div class="bedah"><strong>婚</strong> (hūn, menikah) = 女 (perempuan) + 昏 (hūn, senja). Pola bunyi: 昏 menyumbang bunyi hūn.</div>

Catatan: 奶奶 dan 爷爷 khusus untuk kakek-nenek dari pihak ayah.

|---|---|---|
| 担心 | dānxīn | khawatir |
| 放心 | fàngxīn | tenang (lega) |
| 害怕 | hàipà | takut |
| 生气 | shēngqì | marah |
| 难过 | nánguò | sedih |
| 聪明 | cōngming | pintar |
| 热情 | rèqíng | ramah hangat, antusias |
| 奇怪 | qíguài | aneh |
| 可爱 | kě'ài | lucu (menggemaskan) |
| 年轻 | niánqīng | muda |
| 感兴趣 | gǎnxìngqù | tertarik |
| 满意 | mǎnyì | puas |
| 明白 | míngbai | paham (ngeh) |
| 了解 | liǎojiě | memahami (mendalami) |
| 记得 | jìde | ingat |
| 忘记 | wàngjì | lupa |
| 认为 | rènwéi | berpendapat, menurut |
| 认真 | rènzhēn | serius (sungguh-sungguh) |
| 相信 | xiāngxìn | percaya |

| 愿意 | yuànyì | bersedia, mau |

| 发现 | fāxiàn | menemukan, menyadari |
| 注意 | zhùyì | perhatikan |
| 小心 | xiǎoxīn | hati-hati |
| 爱好 | àihào | hobi |

<div class="contoh"><div class="hz">别担心，我很好。</div><div class="py">Bié dānxīn, wǒ hěn hǎo.</div><div class="id">Jangan khawatir, saya baik-baik aja.</div></div>

<div class="contoh"><div class="hz">他生气了，因为我忘记了。</div><div class="py">Tā shēngqì le, yīnwèi wǒ wàngjì le.</div><div class="id">Dia marah, karena saya lupa.</div></div>

<div class="contoh"><div class="hz">我对中文很感兴趣。</div><div class="py">Wǒ duì Zhōngwén hěn gǎnxìngqù.</div><div class="id">Saya tertarik banget sama bahasa Mandarin.</div></div>

<div class="bedah"><strong>忘</strong> (wàng, lupa) = 亡 (wáng, musnah, hilang) + 心 (hati). "Hati yang hilang" = lupa. Pola makna yang rapi.</div>

<div class="bedah"><strong>怕</strong> (pà, takut) = 忄 (hati, perasaan) + 白 (bái, putih). Takut sampai muka memutih. Pola makna.</div>

<div class="bedah"><strong>认</strong> (rèn, mengenali) = 讠 (ucapan) + 人 (orang). "Ucapan seseorang" = mengenali, mengakui. Pola makna.</div>

<div class="bedah"><strong>聪</strong> (cōng, pintar) = 耳 (telinga) di kiri menandakan kata ini soal pendengaran. Telinga yang tajam dianggap tanda orang cerdas. Pola makna.</div>

<div class="bedah"><strong>意</strong> (yì, maksud) = 音 (yīn, bunyi) + 心 (hati). "Bunyi hati" = maksud, niat. Pola makna.</div>

Catatan: 担心 vs 放心 itu antonim, khawatir vs lega. 了解 vs 明白, dua-duanya "mengerti", tapi 了解 = memahami lewat proses kenal dan mendalami, 明白 = paham sampai jelas (ngeh). 记得 vs 忘记 juga pasangan antonim, ingat vs lupa.

## 11.4 Masyarakat & relasi

Orang-orang di sekitarmu: tetangga, rekan kerja, tamu, dan semuanya:

| Hanzi | Pinyin | Arti |
|---|---|---|
| 邻居 | línjū | tetangga |
| 同事 | tóngshì | rekan kerja |
| 客人 | kèrén | tamu |
| 关系 | guānxì | hubungan |
| 关心 | guānxīn | peduli, memperhatikan |
| 照顾 | zhàogù | merawat |
| 聊天 | liáotiān | ngobrol |
| 见面 | jiànmiàn | ketemuan |
| 经理 | jīnglǐ | manajer |
| 校长 | xiàozhǎng | kepala sekolah |
| 司机 | sījī | sopir |
| 欢迎 | huānyíng | selamat datang, menyambut |
| 位 | wèi | kata satuan sopan untuk orang |
| 有名 | yǒumíng | terkenal |
| 遇到 | yùdào | kebetulan ketemu, mengalami |
| 习惯 | xíguàn | kebiasaan |
| 别人 | biéren | orang lain |
| 自己 | zìjǐ | diri sendiri |

<div class="contoh"><div class="hz">我的邻居很热情。</div><div class="py">Wǒ de línjū hěn rèqíng.</div><div class="id">Tetangga saya ramah banget.</div></div>

<div class="contoh"><div class="hz">我们昨天见面了。</div><div class="py">Wǒmen zuótiān jiànmiàn le.</div><div class="id">Kami ketemu kemarin.</div></div>

<div class="contoh"><div class="hz">谢谢你的关心！</div><div class="py">Xièxie nǐ de guānxīn!</div><div class="id">Makasih atas perhatianmu!</div></div>

<div class="bedah"><strong>照</strong> (zhào, di 照顾 = merawat) = 日 (matahari) + 召 (zhào). Pola bunyi: 召 menyumbang bunyi zhào.</div>

<div class="bedah"><strong>客</strong> (kè, tamu) = 宀 (atap) + 各 (gè). Pola bunyi: 各 menyumbang bunyi yang mirip.</div>

Catatan: 位 itu kata satuan sopan untuk orang, mis. 一位客人 (seorang tamu). 关心 vs 照顾, 关心 = peduli di hati, 照顾 = merawat lewat tindakan. 自己 vs 别人, diri sendiri vs orang lain.
