# Bab 13: Dialog HSK 3

Enam dialog situasi nyata memakai kosakata dan tata bahasa HSK 3. Pola Bab 12 dipakai secara natural: komplemen arah dan hasil, 把 dan 被, perbandingan lanjutan, dan kalimat majemuk. Setiap dialog disertai bedah kata kunci dan penjelasan pola.

- [Dialog 1–3](/bab-13-dialog-1-3): Wawancara kerja · Rapat kantor · Tanya arah di jalan
- [Dialog 4–6](/bab-13-dialog-4-6): Belanja + komplain · Telepon bikin janji · Curhat + kasih saran

> Audio dialog menyusul. Untuk sekarang, baca nyaring tiap baris dan tiru polanya.
