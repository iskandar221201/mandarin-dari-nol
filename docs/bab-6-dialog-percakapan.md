# Bab 6: Dialog & Percakapan

Teori tanpa praktik itu seperti punya sepeda tapi tidak pernah dikayuh. Di bab terakhir ini ada 6 dialog pendek dari situasi sehari-hari. Baca tiap baris **keras-keras** (jangan cuma di batin), lalu pelajari bedah katanya.

## Dialog 1: Perkenalan

<div class="hz">A: 你好！</div>
<div class="py">nǐ hǎo!</div>
<div>Halo!</div>
</div>

<div class="contoh">
<div class="hz">B: 你好！</div>
<div class="py">nǐ hǎo!</div>
<div>Halo!</div>
</div>

<div class="contoh">
<div class="hz">A: 你叫什么名字？</div>
<div class="py">nǐ jiào shénme míngzi?</div>
<div>Siapa namamu?</div>
</div>

<div class="contoh">
<div class="hz">B: 我叫 Aska，你呢？</div>
<div class="py">wǒ jiào Aska, nǐ ne?</div>
<div>Nama saya Aska, kalau kamu?</div>
</div>

<div class="contoh">
<div class="hz">A: 我是学生。</div>
<div class="py">wǒ shì xuéshēng.</div>
<div>Saya siswa.</div>
</div>

<div class="contoh">
<div class="hz">B: 你是北京人吗？</div>
<div class="py">nǐ shì Běijīng rén ma?</div>
<div>Apakah kamu orang Beijing?</div>
</div>

<div class="contoh">
<div class="hz">A: 不是，我是中国人。</div>
<div class="py">bù shì, wǒ shì Zhōngguó rén.</div>
<div>Bukan, saya orang Tiongkok.</div>
</div>

**Bedah dialog:**

- **名字** *míngzi* ("nama"): 名 = 夕 + 口 — "mulut (口) yang menyebut di malam hari (夕)" → nama.
- **叫** *jiào* ("memanggil; bernama"): 叫 = 口 + 卩 — memakai mulut (口) untuk memanggil.
- **呢** *ne* ("kalau kamu?"): 呢 = 口 + 尼 — partikel tanya susulan, selalu soal omongan (口).
- **也** *yě* ("juga"): kata fungsi baru dari Bab 5, posisinya sebelum kata kerja.

## Dialog 2: Bertanya umur & asal

<div class="contoh">
<div class="hz">A: 你好！你多大了？</div>
<div class="py">nǐ hǎo! nǐ duō dà le?</div>
<div>Halo! Umurmu berapa?</div>
</div>

<div class="contoh">
<div class="hz">B: 我二十五岁。</div>
<div class="py">wǒ èrshíwǔ suì.</div>
<div>Saya 25 tahun.</div>
</div>

<div class="contoh">
<div class="hz">A: 你是哪儿人？</div>
<div class="py">nǐ shì nǎr rén?</div>
<div>Kamu orang mana?</div>
</div>

<div class="contoh">
<div class="hz">B: 我是北京人。</div>
<div class="py">wǒ shì Běijīng rén.</div>
<div>Saya orang Beijing.</div>
</div>

<div class="contoh">
<div class="hz">A: 你住在哪儿？</div>
<div class="py">nǐ zhù zài nǎr?</div>
<div>Kamu tinggal di mana?</div>
</div>

<div class="contoh">
<div class="hz">B: 我住在北京。</div>
<div class="py">wǒ zhù zài Běijīng.</div>
<div>Saya tinggal di Beijing.</div>
</div>

**Bedah dialog:**

- **岁** *suì*: satuan khusus untuk umur — umur tidak pakai 个.
- **哪** *nǎ* ("yang mana"): 哪 = 口 + 那 — kata tanya (口) yang menunjuk (那).
- **北京** *Běijīng*: 北 = dua orang (匕 + 匕) saling membelakangi = "utara"; 京 = 亠 + 口 + 小 = "ibukota". Jadi 北京 = "ibukota utara".
- **住** *zhù* ("tinggal"): 住 = 亻 + 主 — orang (亻) + pemilik (主) = menetap/tinggal.

</div>

<div class="contoh">
<div class="hz">B: 我想喝茶。</div>
<div class="py">wǒ xiǎng hē chá.</div>

<div class="contoh">

<div class="contoh">
<div class="hz">B: 很好吃，谢谢！</div>
<div class="py">hěn hǎo chī, xièxie!</div>
<div>Enak sekali, terima kasih!</div>
</div>

**Bedah dialog:**

- **菜** *cài* ("masakan; sayur"): 菜 = 艹 + 采 — tumbuhan (艹) yang dipetik (采).
- **茶** *chá* ("teh"): 茶 = 艹 + 人 + 木 — daun (艹) dari pohon (木) yang dipetik orang (人).
- **好吃** *hǎo chī* ("enak", harfiah "baik-dimakan"): pola kata sifat + kata kerja yang sering dipakai untuk rasa.

## Dialog 4: Belanja, tanya harga

<div class="contoh">
<div class="hz">A: 你好！</div>
<div class="py">nǐ hǎo!</div>
<div>Halo!</div>
</div>

<div class="contoh">
<div class="hz">B: 你好！你想买什么？</div>
<div class="py">nǐ hǎo! nǐ xiǎng mǎi shénme?</div>
<div>Halo! Mau beli apa?</div>
</div>

<div class="contoh">
<div class="hz">A: 这个苹果多少钱？</div>
<div class="py">zhège píngguǒ duōshao qián?</div>
<div>Apel ini harganya berapa?</div>
</div>

<div class="contoh">
<div class="hz">B: 三块钱。</div>
<div class="py">sān kuài qián.</div>
<div>Tiga yuan.</div>
</div>

<div class="contoh">
<div class="hz">A: 那个呢？</div>
<div class="py">nàge ne?</div>
<div>Kalau yang itu?</div>
</div>

<div class="contoh">
<div class="hz">B: 那个五块钱。</div>
<div class="py">nàge wǔ kuài qián.</div>
<div>Yang itu lima yuan.</div>
</div>

<div class="contoh">
<div class="hz">A: 好，我买三个。</div>
<div class="py">hǎo, wǒ mǎi sān ge.</div>
<div>Baik, saya beli tiga.</div>
</div>

<div class="contoh">
<div class="hz">B: 好，谢谢！</div>
<div class="py">hǎo, xièxie!</div>
<div>Baik, terima kasih!</div>
</div>

**Bedah dialog:**

- **买** *mǎi* ("membeli"): bentuk sederhana dari 買 — hafalkan sebagai satu kesatuan, jangan dibedah.
- **钱** *qián* ("uang"): 钱 = 钅 (logam) + 戋 — dari zaman uang logam.
- **块** *kuài*: satuan uang versi lisan — 三块钱 = "tiga yuan" (lisan). Versi formalnya pakai 元 (di luar HSK 1).
- **多少** *duōshao* ("berapa", untuk jumlah besar/tak pasti): 多 = 夕 + 夕 — "banyak" = dua malam (夕) bertumpuk.

## Dialog 5: Tanya jalan & waktu

<div class="contoh">
<div class="hz">A: 你好！火车站在哪儿？</div>
<div class="py">nǐ hǎo! huǒchēzhàn zài nǎr?</div>
<div>Halo! Stasiun keretanya di mana?</div>
</div>

<div class="contoh">
<div class="hz">B: 在前面。</div>
<div class="py">zài qiánmian.</div>
<div>Di depan.</div>

<div class="contoh">
<div class="hz">A: 现在几点？</div>
<div class="py">xiànzài jí diǎn?</div>

<div class="contoh">
<div class="hz">B: 现在三点。</div>
<div class="py">xiànzài sān diǎn.</div>
<div>Sekarang jam tiga.</div>
</div>

<div class="contoh">
<div class="hz">A: 谢谢！</div>
<div class="py">xièxie!</div>
<div>Terima kasih!</div>
</div>

<div class="contoh">
<div class="hz">B: 不客气！</div>
<div class="py">bù kèqi!</div>
<div>Sama-sama!</div>
</div>

<div class="contoh">
<div class="hz">A: 再见！</div>
<div class="py">zàijiàn!</div>
<div>Sampai jumpa!</div>
</div>

<div class="contoh">
<div class="hz">B: 再见！</div>
<div class="py">zàijiàn!</div>
<div>Sampai jumpa!</div>
</div>

**Bedah dialog:**

- **站** *zhàn* ("stasiun; berdiri"): 站 = 立 + 占 — berdiri (立) di satu titik (占).
- **请** *qǐng* ("mohon; silakan"): 请 = 讠 + 青 — meminta lewat kata-kata (讠).
- **点** *diǎn* ("jam; pukul"): 点 = 占 + 灬 — titik (占) + api (灬) → titik waktu.
- **钟** *zhōng* (dalam 分钟 "menit"): 钟 = 钅 (logam) + 中 — lonceng logam penanda waktu.

## Dialog 6: Telepon

<div class="contoh">
<div class="hz">A: 喂，你好！</div>
<div class="py">wèi, nǐ hǎo!</div>
<div>Halo! (di telepon)</div>
</div>

<div class="contoh">
<div class="hz">B: 喂，你好！他在家吗？</div>
<div class="py">wèi, nǐ hǎo! tā zài jiā ma?</div>
<div>Halo! Apakah dia (laki-laki) di rumah?</div>
</div>

<div class="contoh">
<div class="hz">A: 他不在家。</div>
<div class="py">tā bù zài jiā.</div>
<div>Dia tidak di rumah.</div>
</div>

<div class="contoh">
<div class="hz">B: 他去哪儿了？</div>
<div class="py">tā qù nǎr le?</div>
<div>Dia pergi ke mana?</div>
</div>

<div class="contoh">
<div class="hz">A: 他去商店了。</div>
<div class="py">tā qù shāngdiàn le.</div>
<div>Dia pergi ke toko.</div>
</div>

<div class="contoh">
<div class="hz">B: 他什么时候回来？</div>
<div class="py">tā shénme shíhou huí?</div>
<div>Kapan dia pulang?</div>
</div>

<div class="contoh">
<div class="hz">A: 明天上午。</div>
<div class="py">míngtiān shàngwǔ.</div>
<div>Besok pagi.</div>
</div>

<div class="contoh">
<div class="hz">B: 好，谢谢！再见！</div>
<div class="py">hǎo, xièxie! zàijiàn!</div>
<div>Baik, terima kasih! Sampai jumpa!</div>
</div>

**Bedah dialog:**

- **喂** *wèi*: sapaan khusus telepon — tidak dipakai untuk menyapa tatap muka.
- **打电话** *dǎ diànhuà* ("menelepon", harfiah "memukul telepon"): 打 = 扌 + 丁 (pakai tangan); 话 = 讠 + 舌 (kata-kata + lidah).
- **回** *huí* ("pulang; kembali"): 回 = 囗 + 口 — mulut (口) kembali masuk ke dalam kotak (囗).
- **什么时候** *shénme shíhou* ("kapan", harfiah "waktu apa"): 时 = 日 + 寸 — matahari (日) + takaran (寸) = waktu.

## Latihan

Tugasmu: **buat 1 dialog sendiri** (6–8 baris) memakai pola dari 6 dialog di atas. Pilih satu situasi:

- (a) kenalan dengan teman baru di sekolah;
- (b) beli buah di toko;
- (c) tanya jam dan arah ke rumah sakit.
