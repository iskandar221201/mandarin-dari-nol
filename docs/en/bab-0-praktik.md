# Chapter 0 · 0.6–0.8: Hands-on Practice

## 0.6: Install a Pinyin keyboard on your phone

Without a Mandarin keyboard, you can't practice typing. Install once, use forever:

**Android (Gboard):** Settings → System → Languages & input → Virtual keyboard → Gboard → Languages → add **中文 (简体)** → choose the **Pinyin** layout.

**iPhone:** Settings → General → Keyboard → Keyboards → Add New Keyboard → **Chinese, Simplified (Pinyin)**.

How to use it: type `nihao`, and 你好 will pop up as a suggestion, pick the right one. This is where the habit of reading pinyin + seeing hanzi starts building.

## 0.7: Study tips so you don't give up in week one

1. **Tones first, vocabulary later.** Wrong tone = wrong meaning. Get used to reading pinyin *with* its tone marks, don't skip them.
2. **Don't write tones with numbers** (ni3 hao3). Always use tone marks (nǐ hǎo), your eyes need to get used to seeing their shapes.
3. **Dissect hanzi, don't memorize blindly.** Every character has components that often leak its meaning. This is covered in depth in [Chapter 3](/en/bab-3-radikal-bedah-hanzi), but start the mindset now.
4. **Typing > handwriting (at first).** Typing with a Pinyin keyboard is the cheapest reading practice there is. Handwriting can come later for your favorite characters.
5. **A little daily > a weekly marathon.** 15 minutes a day beats 3 hours once a week.

## 0.8: Daily tone drill (5 minutes)

Tones are a mouth-muscle + ear skill. The best practice is short but daily:

1. **Tone ladder**, read in order, 5x: mā → má → mǎ → mà → ma. Feel the difference in your throat.
2. **Minimal pairs**, pick one pair from the table in 0.4 (e.g. shì/shí), read them alternately 10x.
3. **Shadowing**, play the example-sentence audio in later chapters (they have play buttons), imitate the tones as closely as you can.
4. **Record yourself**, read 你好吗？我很好，谢谢。你呢？ then listen back. The parts that sound off = tomorrow's homework.

Five minutes a day for a week, and your ears will start noticing on their own when someone else's tones are off.
