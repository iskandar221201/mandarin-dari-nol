# Chapter 11 · 11.13–11.16: Concepts & Function Words

Through Chapter 10 you picked up nouns, verbs, and descriptive adjectives. This page takes you one level up: abstract words (important, influence, opportunity) and function words (conjunctions, adverbs, emphatic particles). These little words are what make your sentences sound grown-up instead of robot-memorized.

## 11.13 Abstract concepts (办法, 变化, 方便, 清楚, 影响, 重要, 主要, 简单, 容易, 难, 机会, 水平, 需要, 应该, 必须, 安静, 干净, etc.)

Abstract adjectives plus three modal verbs you must master: 需要 (to need), 应该 (should), 必须 (must). The difference is simple: 需要 is a need, 应该 is advice, 必须 is an obligation. Don't mix them up.

| Hanzi | Pinyin | Meaning |
|---|---|---|
| 办法 | bànfǎ | way; solution |
| 变化 | biànhuà | change |
| 方便 | fāngbiàn | convenient; easy |
| 清楚 | qīngchu | clear |
| 影响 | yǐngxiǎng | influence |
| 重要 | zhòngyào | important |
| 主要 | zhǔyào | main |
| 简单 | jiǎndān | simple |
| 容易 | róngyī | easy |
| 难 | nán | difficult |
| 机会 | jīhuì | opportunity |
| 水平 | shuǐpíng | level |
| 需要 | xūyào | to need |
| 应该 | yīnggāi | should; ought to |
| 必须 | bìxū | must |
| 安静 | ānjìng | quiet |
| 干净 | gānjìng | clean |
| 差 | chà | bad; poor |
| 短 | duǎn | short |
| 坏 | huài | bad; broken |
| 长 | zhǎng | to grow |
| 旧 | jiù | old; used (things) |
| 老 | lǎo | old (age) |

<div class="contoh"><div class="hz">我需要你的帮助。</div><div class="py">Wǒ xūyào nǐ de bāngzhù.</div><div class="id">I need your help.</div></div>

<div class="contoh"><div class="hz">学习汉语不难，但是需要时间。</div><div class="py">Xuéxí Hànyǔ bù nán, dànshì xūyào shíjiān.</div><div class="id">Learning Mandarin isn't hard, but it takes time.</div></div>

<div class="contoh"><div class="hz">你明天必须早起床。</div><div class="py">Nǐ míngtiān bìxū zǎo qǐchuáng.</div><div class="id">You must get up early tomorrow.</div></div>

<div class="bedah"><strong>机会</strong> (jīhuì, opportunity) = 机 (machine, as in 手机) + 会 (can, HSK 1). The "machine" that lets you "can" = opportunity.</div>

<div class="bedah"><strong>水平</strong> (shuǐpíng, level) = 水 (water, HSK 1) + 平 (flat). A flat water surface = level.</div>

> 💡 Modal pattern: 需要/应该/必须 go straight before the verb, no 的. Example: 需要学习, not 需要的学习.

Note: 长 here is read zhǎng (to grow), not cháng (long, HSK 2). One character, two readings, two meanings.

## 11.14 Conjunctions (不但…而且…, 除了, 或者, 还是, 如果, 然后, 只有…才…, 跟, 关于, 根据, 为了, 为, etc.)

Conjunctions give your sentences logic: conditions, choices, exceptions, purposes. Without them your sentences are just piles of facts.

| Hanzi | Pinyin | Meaning |
|---|---|---|
| 不但……而且…… | bùdàn…érqiě… | not only... but also... |
| 除了 | chúle | except; besides |
| 或者 | huòzhě | or (choice) |
| 还是 | háishì | or (in questions) |
| 如果 | rúguǒ | if |
| 然后 | ránhòu | then |
| 只有……才…… | zhǐyǒu…cái… | only if... then... |
| 跟 | gēn | with |
| 关于 | guānyú | about; regarding |
| 根据 | gēnjù | according to |
| 为了 | wèile | in order to; for the sake of |
| 为 | wèi | for |
| 经过 | jīngguò | to pass through |

<div class="contoh"><div class="hz">如果明天下雨，我们就不去。</div><div class="py">Rúguǒ míngtiān xià yǔ, wǒmen jiù bù qù.</div><div class="id">If it rains tomorrow, we won't go.</div></div>

<div class="contoh"><div class="hz">我跟朋友一起吃饭。</div><div class="py">Wǒ gēn péngyou yīqǐ chī fàn.</div><div class="id">I'm eating with friends.</div></div>

<div class="contoh"><div class="hz">他不但会说汉语，而且会写汉字。</div><div class="py">Tā bùdàn huì shuō Hànyǔ, érqiě huì xiě Hànzì.</div><div class="id">He can not only speak Mandarin but also write characters.</div></div>

<div class="bedah"><strong>如果</strong> (rúguǒ, if) = 如 + 果 (fruit, from 水果 HSK 2). "If" + "fruit" = if. Remember the fruit, remember the word.</div>

<div class="bedah"><strong>为了</strong> (wèile, in order to) = 为 (for, this chapter) + 了 (HSK 1). For + the completion marker = the goal you want to reach.</div>

> 💡 还是 vs 或者: use 还是 when you are asking someone to pick (undecided), 或者 in statements (free choice). Question: 你喝茶还是喝咖啡？ Statement: 喝茶或者喝咖啡都可以.

## 11.15 Time & frequency adverbs (刚才, 后来, 过去, 最近, 马上, 终于, 一直, 经常, 突然, 总是, 以前, 半, 刻, 分, 万, 久, etc.)

Time adverbs answer "when" and "how often". They usually sit at the start of the sentence or right before the verb.

| Hanzi | Pinyin | Meaning |
|---|---|---|
| 刚才 | gāngcái | just now |
| 后来 | hòulái | later (on) |
| 过去 | guòqù | the past |
| 最近 | zuìjìn | recently |
| 马上 | mǎshàng | right away |
| 终于 | zhōngyú | finally |
| 一直 | yīzhí | continuously |
| 经常 | jīngcháng | often |
| 突然 | tūrán | suddenly |
| 总是 | zǒngshì | always |
| 以前 | yǐqián | before; in the past |
| 半 | bàn | half |
| 刻 | kè | quarter of an hour |
| 分 | fēn | minute |
| 万 | wàn | ten thousand |
| 久 | jiǔ | long (time) |
| 最后 | zuìhòu | final; in the end |
| 一共 | yígòng | altogether |
| 一会儿 | yíhuìr | a while |
| 先 | xiān | first |

<div class="contoh"><div class="hz">他刚才出去了。</div><div class="py">Tā gāngcái chūqù le.</div><div class="id">He just went out.</div></div>

<div class="contoh"><div class="hz">以前我不会说汉语，现在我会一点。</div><div class="py">Yǐqián wǒ bù huì shuō Hànyǔ, xiànzài wǒ huì yīdiǎn.</div><div class="id">I couldn't speak Mandarin before; now I can a little.</div></div>

<div class="contoh"><div class="hz">我们一直学习到晚上十点。</div><div class="py">Wǒmen yīzhí xuéxí dào wǎnshang shí diǎn.</div><div class="id">We kept studying until 10 at night.</div></div>

<div class="bedah"><strong>过去</strong> (guòqù, the past) = 过 (to pass, this chapter) + 去 (to go, HSK 1). What has "passed and gone" = the past.</div>

<div class="bedah"><strong>最近</strong> (zuìjìn, recently) = 最 (most, HSK 2) + 近 (near, HSK 2). The time "nearest" to now = recently.</div>

> 💡 三点半 = half past three (half toward 4). 一刻 = 15 minutes: 三点一刻 = a quarter past three.

## 11.16 Function words & emphasis (啊, 把, 被, 过, 地, 更, 比较, 极, 多么, 只/只, 像, 向, 越, 一定, 其实, 当然, 特别, 其他, 一般, 一样, 一边, 一直, 又, 短, 老, 旧, 差, 坏, 种, 双, 段, 坏, etc.)

Small words with big impact: particles, markers, and emphasis words. Three of them, 把, 被, and 过, each have their own grammar pattern taught fully in Chapter 12. For now, just learn their basic meanings.

| Hanzi | Pinyin | Meaning |
|---|---|---|
| 啊 | a | exclamation particle ("ah", "oh") |
| 把 | bǎ | to hold (function word; full pattern in Chapter 12) |
| 被 | bèi | by (passive; full pattern in Chapter 12) |
| 过 | guò | to pass (experience pattern in Chapter 12) |
| 地 | de | adverbial marker ("-ly") |
| 更 | gèng | more; even more |
| 比较 | bǐjiào | relatively; quite |
| 极 | jí | extremely |
| 多么 | duōme | how (exclamatory) |
| 只 | zhī | measure word for animals |
| 只 | zhǐ | only |
| 像 | xiàng | to resemble; like |
| 向 | xiàng | towards |
| 越 | yuè | the more... |
| 一定 | yídìng | certainly |
| 其实 | qíshí | actually |
| 当然 | dāngrán | of course |
| 特别 | tèbié | especially; very |
| 其他 | qítā | other |
| 一般 | yībān | generally; ordinary |
| 一样 | yíyàng | the same |
| 一边 | yībiān | while (doing two things) |
| 又 | yòu | again; also |
| 起来 | qǐlái | to get up (complement patterns in Chapter 12) |
| 双 | shuāng | a pair |
| 段 | duàn | section; part |
| 几乎 | jīhū | almost |

<div class="contoh"><div class="hz">他高兴地说：“我回来了！”</div><div class="py">Tā gāoxìng de shuō: "Wǒ huílái le!"</div><div class="id">He said happily, "I'm back!"</div></div>

<div class="contoh"><div class="hz">其实我不饿。</div><div class="py">Qíshí wǒ bù è.</div><div class="id">Actually, I'm not hungry.</div></div>

<div class="contoh"><div class="hz">他跟我一样高。</div><div class="py">Tā gēn wǒ yíyàng gāo.</div><div class="id">He's as tall as me.</div></div>

<div class="bedah"><strong>多么</strong> (duōme, how!) = 多 (many, HSK 1) + 么 (from 什么, HSK 1). "Many-how" = how! Used for exclamations: 多么漂亮！</div>

<div class="bedah"><strong>一边</strong> (yībiān, while) = 一 (one, HSK 1) + 边 (side, from 旁边 HSK 1). One side doing this, the other side doing that: 一边…一边….</div>

> 💡 地 (de) marks the manner adverb: adjective + 地 + verb. Don't confuse it with 的 (possessive marker, HSK 1).
