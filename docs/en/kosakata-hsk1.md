# HSK 1 Vocabulary List

All the HSK 1 vocabulary used in this book — ±150 words, grouped by category. Every word in this book is taken from this list — no "rogue" words.

> **Memorize gradually, following the chapter order** — don't try to memorize them all at once. Chapter 1 uses the greetings group, Chapter 2 uses numbers & time, and so on. This table is a cheat sheet, not a marathon-memorizing spot.
